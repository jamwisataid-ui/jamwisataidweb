# Proposed page topology

This topology uses the supplied concept image as structural inspiration while making the page shorter, calmer, and more conversion-focused.

1. **Compact utility bar** — license, operating hours, phone number; hidden or condensed on mobile.
2. **Sticky navigation** — logo, Umrah, Wisata, Tentang, Testimoni, Artikel, and a primary WhatsApp action.
3. **Hero** — Makkah-led photography, specific value proposition, primary package CTA, secondary consultation link.
4. **Overlapping trust rail** — license, years operating, jamaah served, and review proof. Only verified figures may be published.
5. **Package discovery** — Umrah/Wisata switch, three featured packages, concise comparison facts, and package-aware consultation.
6. **Why Jam Wisata** — asymmetric story block, operational proof, and a small statistics cluster.
7. **Included facilities** — compact icon-led strip or bento layout; no second generic three-column card row.
8. **Destinations** — editorial image grid for selected halal-tour destinations.
9. **Jamaah proof** — one featured video plus two concise quotes; remaining videos load on demand.
10. **Journey gallery and guidance** — selected documentation plus three latest/high-intent articles.
11. **Partners and final CTA** — airline/payment proof, focused consultation banner, then a simplified legal footer.

## Page-level behavior

- Sticky navigation after the hero begins to leave the viewport.
- Smooth anchor navigation with reduced-motion support.
- Mobile package cards use horizontal snap only when necessary; desktop uses an open comparison grid.
- Images reveal gently with opacity/transform; no parallax that harms readability or performance.
- WhatsApp CTAs include the selected package name in the prefilled message.
- Video embeds use poster images and instantiate YouTube only after user intent.
