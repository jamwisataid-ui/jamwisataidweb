# QPC Uthmani Hafs font

`UthmanicHafs_V22.ttf` is the unmodified KFGQPC Hafs Uthmanic Script font (v22), downloaded from the [Quranic Universal Library font page](https://qul.tarteel.ai/resources/font/245) / [font file](https://static-cdn.tarteel.ai/qul/fonts/UthmanicHafs_V22.ttf).

Copyright © 2010 King Fahd Glorious Quran Printing Complex (KFGQPC). The end-user licence embedded in the font grants free use, copying, and distribution, provided the font is not sold, modified, reverse engineered, or offered as a separate product. Keep the font file unchanged when updating it.

The font is bundled with the application so the offline Qur'an and Doa & Dzikir screens keep their Arabic typeface without a network connection. The Latin script and translations continue to use the existing typography.
