# Doa & Dzikir data sources

- `daily-dua.json`, `selected-dua.json`, `morning-dhikr.json`, `evening-dhikr.json`, and `dhikr-after-salah.json` are Indonesian snapshots from `fitrahive/dua-dhikr` (MIT), downloaded 2026-10-15. The dataset provides Arabic, transliteration, Indonesian translation, notes, benefits, and per-item hadith/source references.
- `travel-dua.json` is an Indonesian snapshot of the `Doa Perjalanan` group from EQuran.id, downloaded 2026-10-15. It is based on Hisnul Muslim and includes references in the `source` field.
- `sacred-land.json` is a snapshot of the Haji/Umroh category from the open-source Muslim API/noor dataset, downloaded 2026-10-15. Its documented source is *Kumpulan Doa Sehari-hari*, Kemenag Jatim. Transliteration is intentionally left empty because the source does not provide it.

Do not generate or silently alter devotional content. Review source changes before replacing these snapshots.
